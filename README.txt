TIDY BY TABB SERVICE PHONE COLUMN

This displays the client's phone number between Client and Service
on the Services dashboard table.

The phone number is clickable and uses a tel: link, which makes quick
calling easy on phones and supported desktop apps.

- admin/js/ui.js
