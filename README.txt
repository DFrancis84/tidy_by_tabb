# Tidy by Tabb Static Website

Files included:
- `index.html`
- `style.css`

## Setup
1. Put both files in your site repo.
2. Add the logo/header image here:
   `assets/tidy-by-tabb-header.png`
3. Add gallery images here:
   `assets/gallery/`
4. Replace every `YOUR_GOOGLE_FORM_LINK_HERE` with the Google Form link.
5. Replace social links in the Socials modal.

## Notes
This version uses modern transition panels through full-page sections, glass cards, mobile hotbar navigation, and the pink/teal/blue color palette from the provided Tidy by Tabb image.
