# Tidy by Tabb Gallery Manager v1

Replace the existing `/admin` folder with the included `/admin` folder, or copy these three files over the current versions:

- `admin/index.html`
- `admin/css/styles.css`
- `admin/js/script.js`

## Included in v1

- Gallery cards
- Search and filters
- Add/edit drawer
- Before/after URL previews
- Draft and published states
- Public Gallery visibility selection
- Dashboard statistics
- Local browser storage
- Delete confirmation
- Responsive mobile layout

## Important

This version uses `localStorage` for temporary demo data. It does not upload images, write to Google Drive, publish to the live website, or authenticate users yet.
